# すべての IDN ホストを例外なく遮断する

`xn--` で始まるラベルを一つでも含むホストへの遷移は、正規の日本語ドメインも含めてすべて遮断する。許可リストも、警告ページから先へ進む手段も用意しない。Chrome の IDN 表示判定は、紛らわしい文字のリストに一文字漏れがあるだけで回避された（`аррӏө.com` の `ө`）。類似度で判定する方式には、同じ種類のすり抜けが必ず残る。作者は日本語ドメインを使わないので、誤検知の代償は小さい。

## Considered Options

- **文字種で判定する**（漢字やかなは通し、キリル文字などは止める）: 日本語ドメインを通せる。ただし、許可した文字種の中にも見た目の紛らわしい文字がある。
- **見た目の類似度で判定する**（confusables の skeleton を有名ドメインと照合する）: Chrome と同じ方式で、今回回避された。
- **許可リストと「今回だけ進む」**: ソーシャルエンジニアリングで押させられる余地が残る。必要になったら追加する候補として残す。
