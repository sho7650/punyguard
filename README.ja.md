# PunyGuard

[English](README.md)

国際化ドメイン名（IDN）への遷移をすべて止める Chrome 拡張機能（Manifest V3）です。IDN とは、ラベルのどれかが `xn--` で始まるホストのことです。止めたページの代わりに、何を止めたかを説明する警告ページ（拡張機能に同梱）を表示します。

## なぜ作ったか

Chrome は、ほかの文字と紛らわしい文字を含むドメインを Punycode で表示します。この判定は紛らわしい文字のリストに頼っていて、そこに `ө`（U+04E9）が入っていませんでした。そのため、5文字すべてがキリル文字の `аррӏө.com`（`xn--80a6aa68c8d.com`）は Chrome 154 でも Unicode のまま表示され、`apple.com` と見分けがつきませんでした（[記事](https://www.gizmodo.jp/article/2610-chrome-phishing-domain-bypass/)）。

文字の見た目の似かたで判定する方式には、このような漏れが必ず残ります。PunyGuard は判定をせず、IDN ホストを一律に止めます。

## 止めるもの

| 止める                                                                   | 止めない                                                    |
| ------------------------------------------------------------------------ | ----------------------------------------------------------- |
| `xn--` のラベルを含むホスト（トップレベルドメインも含む）                | パスやクエリの非 ASCII 文字（`ja.wikipedia.org/wiki/東京`） |
| ページ全体と iframe                                                      | 画像やスクリプトなどのサブリソース                          |
| クリック、アドレスバーへの入力、リダイレクト、外部アプリから開いたリンク |                                                             |

- **正規の IDN も止まります**。`日本語.jp` のような日本語ドメインも対象です。許可リストも、警告ページから先へ進む手段もありません（[ADR-0001](docs/adr/0001-block-all-idn-hosts.md)）。
- 警告ページには、元の URL（リンクにはしない）、ホストの Unicode 表記と Punycode 表記、非 ASCII 文字ごとの文字種とコードポイントが出ます。Chrome の表示言語が日本語なら日本語で、それ以外なら英語で表示します。
- 既知の誤検知: userinfo に `xn--` を含む URL（例: `https://xn--a@example.com/`）も止まります。

## インストール

配布は GitHub だけで、Chrome ウェブストアには公開していません。

1. [Releases](https://github.com/sho7650/punyguard/releases) から `punyguard-vX.Y.Z.zip` をダウンロードし、消さないフォルダに展開します。Chrome はこのフォルダから拡張機能を読み込みます。
2. `chrome://extensions` を開き、「デベロッパー モード」をオンにして、「パッケージ化されていない拡張機能を読み込む」でそのフォルダを選びます。
3. 「サイトへのアクセス」は「すべてのサイト」のままにします（下を参照）。

更新するときは、フォルダの中身を新しい Release のもので置き換え、拡張機能のカードの再読み込みボタンを押します。

ソースからビルドする場合は、[Development](README.md#development)（英語）の手順で `dist/` を作り、それを読み込みます。

## 権限とプライバシー

| 権限                    | 理由                                                                                                                                                                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `declarativeNetRequest` | IDN ホストに一致するルールを1本だけ登録するため。ルールは Chrome 自身が適用するので、拡張機能が閲覧内容を見ることはありません                                                                                                                |
| `<all_urls>`            | 止めるだけでなく警告ページへ転送するルールには、転送する URL へのホスト権限が要るため。転送するので、`ERR_BLOCKED_BY_CLIENT` だけの画面ではなく、なぜ止めたかを説明できます（[ADR-0002](docs/adr/0002-redirect-to-bundled-warning-page.md)） |

PunyGuard は content script を持たず、外部と通信せず、何も保存しません。

### 「サイトへのアクセス」は「すべてのサイト」のままにする

`chrome://extensions` で「サイトへのアクセス」を「クリック時」や特定のサイトだけに制限すると、転送が働かなくなり、IDN ホストが止まらなくなります。PunyGuard はこれを検知して、ツールバーアイコンにバッジ `!` を出します。

### バッジの `!`

ツールバーアイコンの `!` は、**遮断が効いていない**ことを表します。アイコンにマウスを重ねると、ツールチップに原因が出ます。

- **遮断ルールを登録できませんでした**: `chrome://extensions` で拡張機能を再読み込みします。それでも消えなければ、同じ画面から service worker のコンソールを開いてエラーを確かめます。
- **サイトへのアクセスを「すべてのサイト」にしてください**: 「すべてのサイト」に戻します。

両方とも問題がなくなれば、バッジは消えます。

## 既知の制限

- 警告ページが新しいタブの最初のページで、そこから別のページへ移り、ブラウザの戻るボタンで警告ページに戻ってきた場合、「前のページに戻る」が表示されますが、押しても何も起きません（前のページがないため）。「このタブを閉じる」は使えます。
